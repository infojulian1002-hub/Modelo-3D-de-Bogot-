# Proyecto: Bogotá 3D (zona pequeña)
Mapa web 3D (MapLibre + GLB de Blender), publicado en GitHub Pages con GitHub Actions.

## Reglas para ahorrar tokens
- Responde en español, en máximo 5 líneas, salvo que se pida más.
- No leas `data/`, `renders/`, `models/` ni archivos binarios.
- Lee solo los archivos que la tarea nombre; usa `grep` antes de abrir un archivo completo.
- Edita fragmentos; no reescribas archivos completos.
- Una tarea por sesión. Si el contexto pasa de 50 %, propón abrir una sesión nueva.
- Pide confirmación antes de cambios grandes.

## Bitácora
Al terminar cada tarea agrega al final de `BITACORA.md`: fecha, autor, proveedor y modelo, agente, prompt resumido,
qué se hizo, problemas y pendientes. No borres entradas. Si no conoces un dato, escribe "pendiente".
